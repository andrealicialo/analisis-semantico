# Análisis Semántico y Código Intermedio

Práctica de Tecnología de Compiladores.

## Ejercicios

### Ejercicio 1
Analizador semántico basado en tabla de símbolos.

### Ejercicio 2
Comprobación y propagación de tipos.

### Ejercicio 3
Tokens con atributos y comprobaciones semánticas.

### Ejercicio 4
Generación de código intermedio para expresiones aritméticas.

Ejemplo:

resultado = a + b * c;

Código:

t1 = b * c
t2 = a + t1
resultado = t2

### Ejercicio 5

### Ejercicio 6
Análisis de declaraciones y asignaciones.

### Ejercicio 7
Código intermedio para if/else.

### Ejercicio 8
Código intermedio para while.
